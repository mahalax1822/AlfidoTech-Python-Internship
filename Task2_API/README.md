# 🌦️ Weather Information App

## 📌 Project Overview

The Weather Information App is a Python application that retrieves real-time weather information for any city using the OpenWeatherMap API. It demonstrates API integration, JSON data handling, user input processing, and exception handling.

---

## 🎯 Objective

To learn how Python communicates with external APIs, parses JSON responses, and handles errors while displaying real-time weather information.

---

## ✨ Features

- Get real-time weather details
- Search weather by city name
- Display:
  - City Name
  - Temperature
  - Feels Like Temperature
  - Humidity
  - Weather Description
  - Wind Speed
- Handle invalid city names
- Handle network/API errors

---

## 🛠️ Technologies Used

- Python 3.x
- Requests Library
- OpenWeatherMap API
- JSON

## ▶️ How to Run

1. Install the Requests library

```
pip install requests
```

2. Open `weather_app.py`

3. Replace the API key with your own:

```python
API_KEY = "YOUR_API_KEY"
```

4. Run the program:

```
python weather_app.py
```

5. Enter a city name.
