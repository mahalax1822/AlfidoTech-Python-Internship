# Student Record Management System

## Objective
This project is a Python-based Student Record Management System that demonstrates file handling and automation. It allows users to add, view, search, update, and delete student records, which are stored permanently in a text file.

## Features
- Add student records
- View all student records
- Search by roll number
- Update student details
- Delete student records
- File handling using text files
- Exception handling

## Technologies Used
- Python 3.x
- File Handling
- OS Module

## Files
- student_management.py – Main Python program
- students.txt – Stores student records
